# Security Policy

This is an unofficial OSS project for Gennai-compatible civic AI app development.

Please do not include real personal data, confidential documents, access tokens, or production secrets in issues, pull requests, screenshots, eval fixtures, or logs.

For vulnerabilities in this repository, open a private security advisory if available, or contact the maintainer privately.

For vulnerabilities in official Digital Agency repositories, use the official security reporting process of those repositories.
