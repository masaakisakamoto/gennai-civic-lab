# v0.7 implementation notes

v0.7 is focused on making `gennai-civic-lab` credible for external announcement.

## Main theme

Launch-ready OSS:

- stronger RAG reproducibility
- explicit release checks
- social launch assets
- more usable Local Runner

## Technical changes

### Persistent BM25 index

`apps/citizen_faq_rag/indexing.py` builds a JSON BM25 index from Markdown corpus files. The index stores corpus metadata, term counts, document frequencies, and document metadata.

### Corpus versioning

Each index has a stable `corpus_fingerprint`. This allows the app to detect whether an index was built from the same corpus currently being searched.

### Retrieval modes

`citizen_faq_rag` now supports:

- `lexical`
- `bm25`
- `hybrid`
- `persistent_bm25`
- `hybrid_persistent`

### Local Runner file input

The browser Local Runner can now encode selected text-like files and send them in `inputs.files`, matching the SDK's `normalize_files()` helper.

### Release readiness

`scripts/release_readiness.py` checks that the critical launch artifacts exist and writes a Markdown/JSON report.

## Design principle

v0.7 intentionally keeps all new features dependency-free. The goal is not maximum search sophistication. The goal is reproducible civic AI engineering that is easy to inspect, run, and explain.
