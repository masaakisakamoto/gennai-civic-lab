# v0.6 Implementation Notes

v0.6 focuses on operational readiness.

## Added

- `packages/gennai_observability`
  - JSONL trace spans
  - dependency-free metrics summary
  - operational report builder
- `scripts/generate_demo_traces.py`
- `scripts/generate_ops_report.py`
- `make demo-traces`
- `make ops-report`
- deployment blueprints for local, Docker Compose, AWS, and Azure
- operations guide

## Why this matters

A civic AI app should not only work in a demo. It should also be testable, observable,
and promotable through a repeatable evidence trail. v0.6 makes that visible without
introducing heavy dependencies or unsafe logging defaults.

## Non-goals

- No production-grade cloud automation yet.
- No raw prompt logging.
- No public Local Runner deployment.
- No vendor-specific observability lock-in.
