# v0.5 Implementation Notes

v0.5 focuses on OSS polish and developer trust.

## Added

- Local Runner v0.5
  - Markdown preview
  - raw outputs tab
  - request payload preview
  - curl export
  - localhost-only endpoint policy retained
- Eval reports
  - `--markdown-report`
  - `--json-report`
  - `make eval-report`
- FAQ corpus import
  - CSV / JSONL to Markdown corpus
  - `scripts/import_faq_corpus.py`
  - `docs/faq-corpus-import.md`
- Audit primitives
  - `AuditEvent`
  - `AuditTimer`
  - `summarize_inputs`
  - JSONL append helper
  - PII-conscious summaries instead of raw text logging
- README presentation upgrade
  - architecture diagram
  - demo image
  - clearer 1-minute flow

## Engineering principle

Public-sector AI OSS should make uncertainty visible. This release improves the ability to:

1. reproduce a call,
2. show the exact request payload,
3. inspect outputs in Markdown,
4. export curl for bug reports,
5. create eval artifacts,
6. avoid logging raw personal data.
