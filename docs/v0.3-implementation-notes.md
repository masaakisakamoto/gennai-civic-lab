# v0.3 implementation notes

v0.3 promotes `citizen_faq_rag` from a placeholder app to a second flagship app.

## What changed

- Added a dependency-free lexical retriever in `apps/citizen_faq_rag/retriever.py`.
- Added a sample municipal FAQ corpus in `apps/citizen_faq_rag/corpus/sample_faq.md`.
- Rebuilt `apps/citizen_faq_rag/app.py` around grounded answers, references, abstention, PII redaction, and prompt-injection notes.
- Expanded `manifests/citizen_faq_rag.gennai.json` for source selection, answer style, safe mode, and max references.
- Added `evals/citizen_faq.yaml` with answerable, unanswerable, PII, and prompt-injection cases.
- Added `tests/test_citizen_faq_rag.py`.
- Added `make run-faq-rag` and `make eval-faq-rag`.
