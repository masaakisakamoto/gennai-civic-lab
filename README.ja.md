# gennai-civic-lab

**自治体・市民・教育現場で使えるAIアプリを、安全に、小さく、検証しながら育てるためのオープンソース実験場です。**

## このプロジェクトについて

`gennai-civic-lab` は、行政・地域・教育・市民サービスの現場で使えるAIアプリを、安全に試し、検証し、少しずつ育てていくためのオープンソースプロジェクトです。

生成AIをただ便利に使うだけでなく、市民への説明責任、安全性、監査性、再現性を大切にしています。

## まず何ができますか？

- 市民向け文章を、やさしい日本語に書き換える
- よくある質問を、RAGで検索して回答する
- ローカル環境でAIアプリを試す
- 入力内容をそのまま残さない監査ログを記録する
- 評価レポートを出力する
- 基本的な安全性テストを実行する

## なぜ公共AIに必要ですか？

公共性の高い領域でAIを使うには、ただ動くだけでは不十分です。

必要なのは、次のような仕組みです。

- 市民にわかりやすく説明できること
- 個人情報を安易に残さないこと
- AIの出力を検証できること
- 小さく試して、段階的に改善できること
- エンジニア以外の人にも理解できること
- 最後は人間が確認できること

## 想定している利用シーン

### 自治体・行政

- 市民向けのお知らせ文をやさしくする
- よくある質問への回答を整理する
- 問い合わせ対応の補助に使う
- AI導入前の小さな検証環境として使う

### 教育・研修

- 生成AIの仕組みを体験する
- AIの安全な使い方を学ぶ
- 企業研修・自治体研修の教材として使う
- RAG、評価、監査ログなどの実践例として使う

### 開発者・研究者

- 公共領域向けAIアプリの土台として使う
- AIアプリの評価・監査・ローカル実行の参考にする
- 小さな civic AI アプリを追加して実験する

## 大切にしている設計思想

### 小さく始める

最初から大きなシステムを作るのではなく、小さなアプリから安全に試します。

### 説明できるAIにする

AIが何をしたのか、なぜその出力になったのかを、後から確認できるようにします。

### 個人情報を安易に残さない

監査ログを残す場合も、入力内容をそのまま保存するのではなく、要約やハッシュなどを使い、安全性を考慮します。

### 現場の人が理解できる

エンジニアだけでなく、行政職員、教育者、市民にも伝わる形を目指します。
